# Ti va di far vedere la tua versione?

[Torna al gioco](../README.md)

## Il modo più semplice

Comprimi la cartella modificata in uno ZIP e passala a un amico. Su Windows: tasto destro → **Comprimi in file ZIP**; su Mac: tasto destro → **Comprimi**.

Prima prova a estrarre quello ZIP e aprire `index.html`: così sai che ci sono tutti i pezzi. Non includere chiavi API o file personali.

## Qui su GitHub

Se hai un account, puoi anche:

- **Segnalare un bug:** apri **Issues → New issue** e racconta cosa succede.
- **Creare una tua versione:** premi **Fork**, poi **Create fork**. Un fork è una copia del progetto nel tuo account.
- **Proporre una modifica:** dopo aver aggiornato il tuo fork, usa **Contribute → Open pull request**. È una proposta: il progetto originale non cambia finché non viene accettata.

Per una piccola modifica puoi aprire un file nel tuo fork e usare la matita. **Commit changes** salva il cambiamento con una breve descrizione. Per caricare file già modificati sul computer puoi usare **Add file → Upload files**, mantenendo le cartelle originali.

Ricorda che un file cambiato su GitHub non aggiorna da solo la copia sul computer: scarica di nuovo lo ZIP per provarlo. E quello che pubblichi in un repository pubblico è visibile a tutti.
