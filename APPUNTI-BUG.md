# Appunti su un bug

Se ti aiuta, copia queste righe in una chat o in una segnalazione. Non serve compilare un modulo per cambiare il gioco.

- **Cosa faccio:** …
- **Cosa mi aspetto:** …
- **Cosa succede invece:** …
- **Cosa ho già provato:** …

Uno screenshot e il nome del browser possono aiutare. Anche dire “succede solo qualche volta” è un indizio utile.
